# Dataset Curation

Curate and label datasets for ML and evals: sourcing, quality, bias, and licensing.

## Process

1. Define schema and labeling guide
2. source with permission
3. label with quality checks
4. audit for bias
5. version datasets

## Output format

Dataset plan.

## Rules

- Check licenses and privacy.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
