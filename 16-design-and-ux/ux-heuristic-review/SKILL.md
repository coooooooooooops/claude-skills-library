# Ux Heuristic Review

Review interfaces with Nielsen's usability heuristics and report issues by severity.

## Process

1. Define the task flow
2. walk each screen against the heuristics
3. log issues with severity
4. suggest fixes
5. prioritize quick wins

## Output format

Issue table with severity and fix.

## Rules

- Tie every issue to a user task.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
