# Color Palette Builder

Create accessible color palettes with contrast checks, scales, and usage rules.

## Process

1. Choose a base hue and mood
2. generate tints and shades
3. assign semantic roles
4. check WCAG contrast
5. provide hex and tokens

## Output format

Palette table with contrast ratios.

## Rules

- Never rely on color alone to convey meaning.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
