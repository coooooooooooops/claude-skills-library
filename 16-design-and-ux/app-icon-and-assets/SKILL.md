# App Icon And Assets

Plan app icons, splash screens, and asset sets with sizes and platform guidelines.

## Process

1. List required sizes per platform
2. define a simple memorable motif
3. ensure legibility small
4. export set
5. test on backgrounds

## Output format

Asset checklist with sizes.

## Rules

- Check the current platform guidelines.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
