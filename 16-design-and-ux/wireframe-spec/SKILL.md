# Wireframe Spec

Describe wireframes for screens with layout, components, content, and states.

## Process

1. List screen purpose
2. define content hierarchy
3. place components
4. specify states
5. note interactions

## Output format

Text wireframe with annotations.

## Rules

- Content first, decoration later.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
