# Form Validation

Build robust forms with validation, errors, accessibility, and submission handling.

## Process

1. Define fields and rules
2. validate client and server
3. show clear inline errors
4. manage submit states
5. protect against double submit

## Output format

Form code with schema validation.

## Rules

- Always validate again on the server.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
