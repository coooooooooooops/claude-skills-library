# Nextjs App

Build Next.js apps with the App Router, server components, routing, data fetching, and deployment.

## Process

1. Plan routes and layouts
2. choose server vs client components
3. fetch data on the server
4. add loading and error boundaries
5. deploy and configure env vars

## Output format

Project structure and key files.

## Rules

- Keep client components at the leaves.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
