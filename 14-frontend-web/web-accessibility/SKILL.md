# Web Accessibility

Audit and fix web accessibility: semantics, keyboard, contrast, ARIA, and screen readers against WCAG.

## Process

1. Check semantic HTML
2. test keyboard navigation and focus
3. verify contrast and text sizing
4. add labels and ARIA only when needed
5. test with a screen reader

## Output format

Issue list with fixes.

## Rules

- Native elements beat ARIA.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
