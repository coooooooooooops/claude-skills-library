# Threejs Scene

Build 3D web scenes with three.js: cameras, lights, materials, models, and animation.

## Process

1. Create scene, camera and renderer
2. add lights and materials
3. load glTF models
4. animate in the render loop
5. optimize and dispose resources

## Output format

Three.js starter and explanation.

## Rules

- Dispose geometries and textures you no longer use.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
