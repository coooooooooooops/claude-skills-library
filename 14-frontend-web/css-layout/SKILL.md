# Css Layout

Solve CSS layout with flexbox, grid, and positioning.

## Process

1. Identify the layout goal
2. choose grid for 2D and flex for 1D
3. set gaps and alignment
4. handle overflow and min-width
5. test at several widths

## Output format

Working CSS and HTML snippet.

## Rules

- Avoid fixed pixel heights where content can grow.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
