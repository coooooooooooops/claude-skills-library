# Responsive Design

Make sites work across phones, tablets, and desktops with fluid layouts and breakpoints.

## Process

1. Start mobile-first
2. use fluid units and clamp
3. set content-driven breakpoints
4. make touch targets 44px
5. test on real widths

## Output format

Responsive CSS and checklist.

## Rules

- Never rely on hover for essential actions.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
