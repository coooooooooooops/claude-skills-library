# Pwa Builder

Turn a website into a Progressive Web App: manifest, service worker, offline, and install prompts.

## Process

1. Create manifest and icons
2. register a service worker
3. choose caching strategy
4. handle updates
5. test install and offline

## Output format

Manifest, service worker, and test steps.

## Rules

- Version caches and handle update flow.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
