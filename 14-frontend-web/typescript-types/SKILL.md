# Typescript Types

Write precise TypeScript types: generics, unions, utility types, and narrowing.

## Process

1. Model domain with discriminated unions
2. use generics for reuse
3. narrow with guards
4. avoid any
5. enable strict mode

## Output format

Typed code and explanation of errors.

## Rules

- Prefer unknown over any.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
