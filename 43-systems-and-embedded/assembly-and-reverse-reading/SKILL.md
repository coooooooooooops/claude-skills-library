# Assembly And Reverse Reading

Read and write basic assembly and understand compiler output for your own code.

## Process

1. Pick an architecture
2. read calling conventions
3. map C to assembly with a compiler explorer
4. trace registers and stack
5. document findings

## Output format

Annotated walkthrough.

## Rules

- Use only on code you own or have permission to study.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
