# Compiler And Parser Basics

Build lexers, parsers, and interpreters for small languages or config formats.

## Process

1. Define grammar
2. write lexer
3. build a recursive-descent parser
4. evaluate the AST
5. add errors with positions

## Output format

Interpreter skeleton.

## Rules

- Start with a tiny grammar and grow it.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
