# Serial Protocols

Implement and debug I2C, SPI, UART, and CAN communication.

## Process

1. Check wiring and voltage levels
2. configure speed and mode
3. read with a logic analyzer
4. add error handling
5. document the protocol

## Output format

Debug steps and code.

## Rules

- Verify logic levels before connecting devices.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
