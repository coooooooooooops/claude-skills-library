# Google Apps Script

Automate Google Sheets, Docs, and Gmail with Apps Script.

## Process

1. Define the task
2. write script with triggers
3. handle quotas
4. test with copies
5. deploy

## Output format

Apps Script code.

## Rules

- Test on a copy of real data.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
