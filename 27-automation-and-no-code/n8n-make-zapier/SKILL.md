# N8n Make Zapier

Build workflows in n8n, Make, and Zapier with webhooks, filters, and data mapping.

## Process

1. Choose tool
2. set up webhook trigger
3. map fields
4. add filters and retries
5. log failures

## Output format

Scenario blueprint.

## Rules

- Keep credentials in the tool's secret store.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
