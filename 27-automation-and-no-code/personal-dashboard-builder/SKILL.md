# Personal Dashboard Builder

Build a personal dashboard aggregating tasks, calendar, and metrics.

## Process

1. List data sources
2. choose tool
3. fetch via APIs
4. design a minimal layout
5. refresh on schedule

## Output format

Dashboard plan and code.

## Rules

- Show only what drives action.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
