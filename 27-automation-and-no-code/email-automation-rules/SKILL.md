# Email Automation Rules

Create email filters, templates, and routing rules to reduce inbox load.

## Process

1. Categorize incoming mail
2. write filters and labels
3. create canned responses
4. schedule triage
5. unsubscribe aggressively

## Output format

Rule set.

## Rules

- Keep rules simple and reviewable.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
