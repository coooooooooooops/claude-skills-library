# Airtable Notion Databases

Design databases in Notion or Airtable: tables, relations, views, and automations.

## Process

1. Define entities
2. create relations and rollups
3. build views
4. add templates and automations
5. keep it simple

## Output format

Database design.

## Rules

- Start with the views you will actually use.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
