# Obsidian Note System

Build a note-taking system in Obsidian or similar: linking, templates, and review.

## Process

1. Define capture and review flow
2. create templates
3. link ideas
4. use tags sparingly
5. schedule review

## Output format

Vault structure.

## Rules

- Optimize for retrieval, not collecting.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
