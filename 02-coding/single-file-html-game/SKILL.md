# Single File Html Game

Ship a fun playable prototype in one file.

## Process

1. Pick the core loop and win/lose conditions.
2. Set up canvas, fixed timestep loop, and input handling (keyboard, touch).
3. Structure code: state, update, render, entities.
4. Add juice: screen shake, particles, sound via WebAudio, tweening.
5. Add persistence with in-memory state or localStorage where allowed.
6. Test on mobile viewport and tune difficulty.

## Output format

A single self-contained .html file.

## Rules

- No external assets unless inlined.
- Make it fun in the first 10 seconds.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
