# Readme Writer

Make a project understandable in 60 seconds.

## Process

1. Identify audience and the single-sentence value proposition.
2. Draft: title, badges, what/why, demo (screenshot or GIF placeholder), install, quickstart, usage, config, roadmap, contributing, license.
3. Verify every command and path actually matches the project.
4. Trim fluff; keep the quickstart copy-pasteable.

## Output format

A complete README.md.

## Rules

- Never invent features.
- Mark unknowns with TODO rather than guessing.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
