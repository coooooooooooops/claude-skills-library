# Vscode Setup

Configure VS Code: extensions, settings, tasks, debugging, and snippets for a language.

## Process

1. Pick extensions per language
2. set formatting on save
3. configure debug launch
4. add tasks
5. share settings

## Output format

Settings and extensions list.

## Rules

- Keep the extension list lean.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
