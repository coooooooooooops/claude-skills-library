# Vim Neovim Guide

Learn Vim and Neovim: motions, text objects, macros, and a minimal config.

## Process

1. Learn core motions
2. use text objects
3. record macros
4. build a small config
5. add plugins gradually

## Output format

Learning path.

## Rules

- Practice a few commands until automatic.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
