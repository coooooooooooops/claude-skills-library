# Keyboard Shortcuts Mastery

Plan learning keyboard shortcuts for your main apps to speed up work.

## Process

1. List your daily actions
2. learn five shortcuts a week
3. replace mouse habits
4. track progress
5. review cheatsheets

## Output format

Weekly shortcut plan.

## Rules

- Learn by use, not by memorizing lists.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
