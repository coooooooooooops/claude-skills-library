# Good First Issues

Create welcoming good-first-issues and onboarding docs for contributors.

## Process

1. Find small isolated tasks
2. write clear context and acceptance criteria
3. link relevant files
4. offer mentoring
5. label

## Output format

Issue templates and docs.

## Rules

- Make the first contribution easy.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
