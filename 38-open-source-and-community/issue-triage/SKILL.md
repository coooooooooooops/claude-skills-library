# Issue Triage

Triage GitHub issues: labels, reproduction, priority, and closing.

## Process

1. Label type and area
2. request reproduction steps
3. assign priority
4. link duplicates
5. close politely when stale

## Output format

Triage workflow and labels.

## Rules

- Be kind to new reporters.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
