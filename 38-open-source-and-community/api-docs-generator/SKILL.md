# Api Docs Generator

Generate API documentation with examples, from OpenAPI or code comments.

## Process

1. Collect endpoints or functions
2. write descriptions and examples
3. document errors
4. publish with a docs tool
5. keep in sync with code

## Output format

API reference.

## Rules

- Every example must run.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
