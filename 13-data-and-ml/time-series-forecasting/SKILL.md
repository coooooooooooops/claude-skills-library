# Time Series Forecasting

Forecast time series with baselines, seasonality, and models like ARIMA, Prophet, or gradient boosting.

## Process

1. Plot and decompose the series
2. set a naive baseline
3. choose a model
4. backtest with rolling windows
5. report prediction intervals

## Output format

Forecast code and backtest results.

## Rules

- Validate with time-ordered splits only.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
