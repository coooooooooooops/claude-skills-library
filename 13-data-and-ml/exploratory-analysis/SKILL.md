# Exploratory Analysis

Run exploratory data analysis: distributions, relationships, segments, and anomalies.

## Process

1. State the question
2. summarize distributions
3. test relationships
4. segment and compare
5. list findings and follow-up questions

## Output format

EDA summary with key charts described.

## Rules

- Separate observations from causal claims.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
