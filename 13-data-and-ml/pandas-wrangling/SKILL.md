# Pandas Wrangling

Clean, reshape, merge, and aggregate data with pandas or polars.

## Process

1. Inspect dtypes and nulls
2. clean and normalize columns
3. join or reshape
4. aggregate
5. validate row counts after each step

## Output format

Readable pandas code with sanity checks.

## Rules

- Check row counts after every join.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
