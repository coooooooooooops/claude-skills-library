# Dashboard Design

Design clear dashboards with the right metrics, charts, and layout.

## Process

1. Identify audience and decisions
2. choose few key metrics
3. match chart to question
4. order from summary to detail
5. add filters and definitions

## Output format

Dashboard wireframe and metric definitions.

## Rules

- Every chart should answer a specific question.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
