# Pytorch Training Loop

Write and debug PyTorch training loops, datasets, and GPU usage.

## Process

1. Define dataset and dataloader
2. build model
3. write train and eval loops
4. add optimizer, scheduler and checkpoints
5. debug with a tiny overfit test

## Output format

Complete training script.

## Rules

- Overfit one batch first to verify the pipeline.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
