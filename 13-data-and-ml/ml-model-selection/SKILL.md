# Ml Model Selection

Choose machine learning models and baselines for tabular, text, image, or time-series problems.

## Process

1. Define target and metric
2. build a simple baseline
3. try gradient boosting or suitable architecture
4. compare with cross-validation
5. pick for performance and simplicity

## Output format

Model comparison table and recommendation.

## Rules

- Always beat a dumb baseline before adding complexity.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
