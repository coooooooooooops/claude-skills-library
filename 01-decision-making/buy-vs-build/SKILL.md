# Buy Vs Build

Compare total cost, speed, control, and risk across buy, adopt, and build.

## Process

1. Define the requirement in must-have and nice-to-have terms.
2. List candidate off-the-shelf options and the custom path.
3. Estimate total cost over 12-24 months: money, build time, maintenance, switching cost.
4. Assess control, lock-in, integration, and learning value (for hobbyists, building can be the goal).
5. Recommend a path and a trigger for revisiting.

## Output format

Comparison table and a recommendation with a revisit trigger.

## Rules

- Include maintenance, not just initial cost.
- Respect that learning and fun are legitimate benefits.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
