# Opportunity Cost

Compare any choice against its best alternative use of the same resources.

## Process

1. Quantify the resource: dollars, hours, energy, attention.
2. List the 3 best alternative uses of the same resource.
3. Estimate return of each in comparable units (money, learning, joy, progress).
4. State the true cost of the choice as 'the best thing I give up'.
5. Decide whether the choice still wins.

## Output format

Side-by-side table of choice vs. alternatives with a verdict.

## Rules

- Include non-financial returns.
- Flag when estimates are rough.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
