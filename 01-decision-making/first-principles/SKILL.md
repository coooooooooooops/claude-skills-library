# First Principles

Strip away assumptions and reconstruct from what is verifiably true.

## Process

1. Write down the problem and the current accepted solution.
2. List every assumption baked into it. Mark each: fact, convention, or guess.
3. Identify the irreducible constraints (physics, math, law, hard budget).
4. Rebuild 2-3 candidate solutions using only the constraints.
5. Compare against the conventional approach and note what is newly possible.

## Output format

Assumption audit table plus rebuilt options and a recommended experiment.

## Rules

- Challenge conventions, not facts.
- Propose a small test to validate the riskiest assumption.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
