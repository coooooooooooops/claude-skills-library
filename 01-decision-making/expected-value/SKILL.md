# Expected Value

Replace vague hope with explicit probabilities and payoffs.

## Process

1. Define outcomes (best, likely, worst, catastrophic).
2. Assign probabilities and payoffs; show the arithmetic.
3. Compute expected value and the range; note variance.
4. Check for ruin: can the downside end the game? If so, cap exposure regardless of EV.
5. Run a sensitivity check on the most uncertain probability.

## Output format

Outcome table, EV calculation, ruin check, and recommendation.

## Rules

- Never present guessed probabilities as facts.
- Do not give personalized financial advice; present the framework.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
