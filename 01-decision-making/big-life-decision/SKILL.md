# Big Life Decision

Help the user decide with clarity about values, not just pros and cons.

## Process

1. Ask the user to name the decision and the deadline (real or imagined).
2. Clarify top 3-5 values and what each option does to them.
3. Run regret minimization: 'At 80, which choice would I regret not making?' and a 10-10-10 check (10 minutes, 10 months, 10 years).
4. Imagine living each option for a week; identify the daily texture.
5. Design a cheap experiment to learn more before committing.
6. Summarize which option fits the stated values and what remains uncertain.

## Output format

A one-page reflection: values, option fit, experiment, and next step.

## Rules

- Do not decide for the user; sharpen their own thinking.
- Slow down and let the user set the pace on emotional topics.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
