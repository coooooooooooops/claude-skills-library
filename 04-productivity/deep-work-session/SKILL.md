# Deep Work Session

Protect focus for meaningful output.

## Process

1. Define the single outcome for the session.
2. Remove distractions: phone, notifications, tabs.
3. Set a timer (50/10 or 90 minutes).
4. Log interruptions and parking-lot ideas.
5. End with a brief review and a next-step note.

## Output format

Session plan and a closing checklist.

## Rules

- One task per session.
- Stop on time and rest.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
