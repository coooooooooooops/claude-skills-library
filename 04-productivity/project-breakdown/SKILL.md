# Project Breakdown

Make the overwhelming concrete.

## Process

1. Define the outcome and constraints.
2. List milestones that each deliver visible value.
3. Break into tasks of at most half a day.
4. Map dependencies and the critical path.
5. Estimate with ranges and add 30% buffer.
6. Plan week one.

## Output format

Milestone/task table and a first-week checklist.

## Rules

- Ship a thin vertical slice early.
- Re-plan weekly.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
