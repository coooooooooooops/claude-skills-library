# Unity Addressables

Manage assets with Unity Addressables: groups, loading, memory, and updates.

## Process

1. Group assets by use
2. load and release asynchronously
3. track handles
4. build and host content
5. test updates

## Output format

Addressables plan.

## Rules

- Always release loaded assets.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
