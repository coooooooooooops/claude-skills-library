# Load Testing

Plan and run load tests with k6, Locust, or JMeter and interpret results.

## Process

1. Define realistic scenarios and targets
2. script ramp-up profiles
3. run against staging
4. monitor resources and latency percentiles
5. report bottlenecks and limits

## Output format

Test script and results analysis.

## Rules

- Never load-test production or third-party services without permission.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
