# Incident Response

Run a production incident: triage, mitigate, communicate, and recover.

## Process

1. Declare severity and roles
2. stabilize by rollback or mitigation first
3. communicate status on a cadence
4. gather timeline evidence
5. hand off to a postmortem

## Output format

Incident checklist, status update templates, and timeline log.

## Rules

- Mitigate before diagnosing root cause.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
