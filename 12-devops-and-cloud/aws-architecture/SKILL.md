# Aws Architecture

Design AWS architectures for web apps, APIs, data pipelines, and event systems with sensible service choices.

## Process

1. Clarify traffic, data and availability needs
2. choose compute, storage and database
3. design networking and IAM least privilege
4. add monitoring and backups
5. estimate monthly cost

## Output format

Architecture sketch, service rationale, and cost estimate.

## Rules

- Verify current pricing and quotas before committing.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
