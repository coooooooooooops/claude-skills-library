# Compound Interest Calculator

Calculate compound growth, loan payoff, and savings goals with formulas and tables.

## Process

1. Collect principal, rate, term and contributions
2. compute with formula
3. show year-by-year table
4. run scenarios
5. note assumptions

## Output format

Table and formulas.

## Rules

- State the assumed rates clearly.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
