# Startup Financial Model

Build startup financial models: unit economics, CAC, LTV, burn, runway, and fundraising needs.

## Process

1. Define revenue drivers
2. model costs and hiring
3. compute CAC, LTV and payback
4. project runway
5. stress-test scenarios

## Output format

Model structure and key metrics.

## Rules

- Make assumptions explicit and adjustable.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
