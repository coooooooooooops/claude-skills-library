# Customer Returns Policy

Write fair returns, refunds, and warranty policies.

## Process

1. Define return window and conditions
2. set refund method
3. handle damaged items
4. write plain language
5. review regularly

## Output format

Policy text.

## Rules

- Check consumer law in your region.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
