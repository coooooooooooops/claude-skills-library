# Etsy Seo

Optimize Etsy shops: tags, titles, categories, and photos for search.

## Process

1. Research buyer search terms
2. write keyword-rich titles
3. fill all tags
4. improve first photo
5. review stats weekly

## Output format

Optimized listing set.

## Rules

- Follow Etsy's current rules.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
