# App Store Release

Publish apps on the App Store and Google Play: listings, review guidelines, signing, and updates.

## Process

1. Prepare accounts and signing
2. write listing and screenshots
3. check review guidelines
4. submit and respond to review
5. plan updates

## Output format

Release checklist.

## Rules

- Read the current store guidelines before submitting.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
