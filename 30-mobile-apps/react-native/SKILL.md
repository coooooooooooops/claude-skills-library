# React Native

Build apps with React Native and Expo: navigation, native modules, and performance.

## Process

1. Set up Expo
2. plan navigation
3. manage state
4. use native APIs
5. optimize lists and images

## Output format

React Native code.

## Rules

- Test on real devices.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
