# Offline First Sync

Design offline-first apps with local storage, sync queues, and conflict resolution.

## Process

1. Choose local store
2. queue changes
3. sync with idempotent endpoints
4. resolve conflicts
5. show sync state

## Output format

Sync architecture.

## Rules

- Define conflict rules up front.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
