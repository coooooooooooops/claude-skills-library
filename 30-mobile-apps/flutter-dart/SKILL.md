# Flutter Dart

Build cross-platform apps with Flutter: widgets, state, navigation, and platform channels.

## Process

1. Plan widget tree
2. choose state management
3. add navigation
4. integrate plugins
5. test on devices

## Output format

Flutter code.

## Rules

- Prefer small composable widgets.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
