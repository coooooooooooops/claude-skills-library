# Push Notifications

Implement push notifications with APNs and FCM, permissions, and relevance.

## Process

1. Set up keys
2. request permission at a good moment
3. send via server
4. segment and rate limit
5. measure opt-in

## Output format

Notification setup.

## Rules

- Ask for permission in context.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
