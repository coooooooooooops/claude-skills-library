# Swiftui Views

Build iOS UIs with SwiftUI: layout, state, navigation, lists, and animations.

## Process

1. Define screens
2. use @State and @Observable
3. build with stacks and lists
4. add NavigationStack
5. test previews

## Output format

SwiftUI code.

## Rules

- Keep views small and state minimal.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
