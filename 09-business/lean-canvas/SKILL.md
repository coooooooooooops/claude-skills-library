# Lean Canvas

One page business model.

## Process

1. Fill each box concisely.
2. Identify the top problem and early adopters.
3. Define unique value proposition.
4. List key metrics and channels.
5. Mark assumptions to test.

## Output format

Lean Canvas table.

## Rules

- Keep each box to a few bullets.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
