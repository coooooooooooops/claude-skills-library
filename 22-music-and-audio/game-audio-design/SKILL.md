# Game Audio Design

Design game audio: music layers, SFX, mixing, and implementation in engines.

## Process

1. List audio events
2. define music states
3. create varied SFX
4. implement with buses and ducking
5. test in context

## Output format

Audio design document.

## Rules

- Vary repeated sounds to avoid fatigue.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
