# Websocket Realtime

Build realtime features with WebSockets or SSE: presence, rooms, reconnection, and scaling.

## Process

1. Choose WebSocket or SSE
2. define message protocol
3. handle reconnect and backoff
4. manage rooms and presence
5. scale with pub/sub

## Output format

Server and client code.

## Rules

- Assume connections drop constantly.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
