# Node Typescript Api

Build Node.js APIs in TypeScript with Express or Fastify, validation, middleware, and testing.

## Process

1. Structure routes, services and data layer
2. validate input with a schema
3. add error middleware
4. add auth and logging
5. test with supertest

## Output format

API project skeleton.

## Rules

- Validate all external input.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
