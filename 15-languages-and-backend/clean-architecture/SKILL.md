# Clean Architecture

Structure applications with layers, ports and adapters, and clear dependency direction.

## Process

1. Identify domain core
2. define interfaces at boundaries
3. keep frameworks outside
4. inject dependencies
5. test the core without infrastructure

## Output format

Folder structure and example.

## Rules

- Dependencies point inward.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
