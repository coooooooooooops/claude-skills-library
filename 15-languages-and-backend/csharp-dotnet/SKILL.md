# Csharp Dotnet

Write modern C# and .NET: ASP.NET Core, LINQ, async/await, dependency injection, and EF Core.

## Process

1. Set up minimal APIs or controllers
2. register services with DI
3. use async end to end
4. model data with EF Core
5. write xUnit tests

## Output format

.NET code.

## Rules

- Never block on async code.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
