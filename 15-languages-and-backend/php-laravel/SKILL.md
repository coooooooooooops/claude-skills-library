# Php Laravel

Build PHP apps with Laravel: routing, Eloquent, queues, validation, and testing.

## Process

1. Define routes and controllers
2. model with Eloquent
3. validate with form requests
4. queue slow work
5. test with Pest or PHPUnit

## Output format

Laravel code.
