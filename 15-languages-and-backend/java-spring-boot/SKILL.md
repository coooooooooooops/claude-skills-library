# Java Spring Boot

Build Spring Boot services: controllers, JPA, config, security, and testing.

## Process

1. Define layers
2. model entities and repositories
3. add validation and exception handlers
4. configure profiles
5. write slice and integration tests

## Output format

Spring project code.

## Rules

- Keep controllers thin.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
