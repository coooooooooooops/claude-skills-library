# Homeschool Planner

Plan homeschool schedules, subjects, and resources by age.

## Process

1. Define goals per child
2. choose resources
3. build weekly rhythm
4. include projects and outings
5. track progress

## Output format

Weekly plan.

## Rules

- Check local requirements.
