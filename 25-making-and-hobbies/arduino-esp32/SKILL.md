# Arduino Esp32

Build Arduino and ESP32 projects: sensors, actuators, wiring, and firmware.

## Process

1. Define the goal and parts
2. draw wiring
3. write firmware with non-blocking loops
4. test each module
5. add power planning

## Output format

Parts list, wiring notes, and code.

## Rules

- Check voltage and current limits before wiring.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
