# Home Automation

Set up smart home automation with Home Assistant, sensors, and routines.

## Process

1. List devices and protocols
2. set up hub
3. create automations
4. add local fallback
5. secure the network

## Output format

Automation plan and YAML.

## Rules

- Prefer local control over cloud where possible.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
