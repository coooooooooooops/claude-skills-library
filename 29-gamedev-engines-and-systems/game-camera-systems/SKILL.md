# Game Camera Systems

Create game cameras: follow, look-ahead, shake, cinematic, and split-screen.

## Process

1. Choose camera style
2. smooth follow with damping
3. add look-ahead
4. handle collisions and bounds
5. add shake responsibly

## Output format

Camera scripts.

## Rules

- Keep motion sickness in mind.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
