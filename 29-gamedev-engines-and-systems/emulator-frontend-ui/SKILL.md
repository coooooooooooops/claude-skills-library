# Emulator Frontend Ui

Design emulator or game-launcher frontends: library views, controller navigation, artwork, and settings, for legally obtained software.

## Process

1. Define library structure
2. design grid and detail views
3. support gamepad navigation
4. add metadata and artwork fetching
5. store settings

## Output format

Launcher UI plan.

## Rules

- Support only software the user legally owns.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
