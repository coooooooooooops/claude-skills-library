# Godot 2d Platformer

Build Godot 4 2D platformers: movement feel, coyote time, buffering, tilemaps, and enemies.

## Process

1. Create CharacterBody2D
2. add gravity, variable jump, coyote time and input buffering
3. build with TileMapLayer
4. add enemies and hazards
5. add checkpoints

## Output format

Player script and level setup.

## Rules

- Feel matters more than features.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
