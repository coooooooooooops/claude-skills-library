# Combat System Design

Design melee, ranged, and ability combat: hitboxes, cooldowns, damage models, and feedback.

## Process

1. Define combat pillars
2. build hit detection
3. add damage and status effects
4. tune cooldowns
5. add hit feedback

## Output format

Combat design and code.

## Rules

- Readable combat beats complex combat.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
