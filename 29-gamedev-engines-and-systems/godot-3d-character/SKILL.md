# Godot 3d Character

Create Godot 4 3D character controllers: movement, camera, jumping, slopes, animation trees.

## Process

1. Use CharacterBody3D
2. implement movement with acceleration
3. add third-person camera with spring arm
4. blend animations with AnimationTree
5. handle slopes and coyote time

## Output format

Controller script and scene.

## Rules

- Separate input, movement, and animation.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
