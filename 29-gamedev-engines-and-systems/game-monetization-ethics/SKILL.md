# Game Monetization Ethics

Plan fair game monetization: premium, DLC, ads, and cosmetic items without dark patterns.

## Process

1. Define audience
2. choose model
3. price against value
4. avoid manipulative loops
5. plan community trust

## Output format

Monetization plan.

## Rules

- No deceptive mechanics.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
