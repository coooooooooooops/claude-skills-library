# Game State Machines

Implement finite and hierarchical state machines for players, enemies, and game flow.

## Process

1. List states and transitions
2. implement with enum or node-based states
3. keep enter, update, exit hooks
4. log transitions
5. test edge cases

## Output format

State machine code.

## Rules

- One active state at a time.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
