# Godot Multiplayer

Build Godot 4 multiplayer: ENet, authority, spawners, synchronizers, RPCs, lobbies, and prediction.

## Process

1. Choose server or peer topology
2. set multiplayer authority
3. use MultiplayerSpawner and Synchronizer
4. write RPCs with correct modes
5. add lobby and reconnection
6. test with latency

## Output format

Scene setup and scripts.

## Rules

- The server owns game state.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
