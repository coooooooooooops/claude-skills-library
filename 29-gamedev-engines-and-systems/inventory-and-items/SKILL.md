# Inventory And Items

Design inventory, items, equipment, and crafting systems with data-driven definitions.

## Process

1. Define item data schema
2. implement stacks and slots
3. add equipment and stats
4. design crafting recipes
5. handle UI and saves

## Output format

Item system design.

## Rules

- Keep items as data, not code.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
