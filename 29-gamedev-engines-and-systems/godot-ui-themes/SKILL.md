# Godot Ui Themes

Build Godot 4 UI with Control nodes, containers, themes, and responsive layouts.

## Process

1. Plan screen layouts with containers
2. create a Theme resource
3. handle focus and gamepad navigation
4. scale for resolutions
5. animate transitions

## Output format

UI scene structure and scripts.

## Rules

- Use containers instead of manual positions.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
