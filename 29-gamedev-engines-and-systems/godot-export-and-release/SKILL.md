# Godot Export And Release

Export and publish Godot games to desktop, web, and mobile with presets and optimization.

## Process

1. Install templates
2. configure export presets
3. set icons and versions
4. optimize assets
5. test builds and publish on itch or Steam

## Output format

Release checklist.

## Rules

- Test the exported build, not only the editor.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
