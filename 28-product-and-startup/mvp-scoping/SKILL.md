# Mvp Scoping

Scope a minimum viable product to test the riskiest assumption fast.

## Process

1. Identify riskiest assumption
2. define the smallest test
3. cut everything else
4. set a deadline
5. define success metric

## Output format

MVP scope.

## Rules

- An MVP is a learning tool.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
