# Okr For Startups

Set lightweight OKRs for early-stage teams.

## Process

1. Pick a single priority
2. set 3 key results
3. assign owners
4. check weekly
5. reset quarterly

## Output format

Startup OKR sheet.

## Rules

- Focus on one thing per quarter.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
