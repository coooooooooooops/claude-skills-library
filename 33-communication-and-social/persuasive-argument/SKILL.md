# Persuasive Argument

Build persuasive arguments with claims, evidence, and counterpoints ethically.

## Process

1. State the claim
2. give evidence
3. address counterarguments
4. structure for the audience
5. end with a clear ask

## Output format

Argument outline.

## Rules

- Be honest; no manipulation.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
