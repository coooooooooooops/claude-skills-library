# Game Juice Polish

Make every action feel good.

## Process

1. Identify key moments: hit, collect, win, fail.
2. Add anticipation, impact, and follow-through.
3. Layer visual and audio feedback with restraint.
4. Tune timing; keep inputs responsive.
5. Offer an accessibility toggle for effects.

## Output format

Checklist of effects with code ideas.

## Rules

- Never sacrifice readability for flash.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
