# Shop Sim Economy

Make running a shop satisfying.

## Process

1. Define the core service loop and customer needs.
2. Model prices, costs, and upgrade ROI.
3. Design unlock cadence and variety.
4. Add events and light narrative.
5. Balance idle vs. active play.

## Output format

Economy tables and loop diagram.

## Rules

- Every upgrade should change how the player plays.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
