# Narrative Dialogue

Dialogue that sounds like people.

## Process

1. Know each speaker's goal and voice.
2. Use subtext; cut small talk.
3. For branching: map nodes and consequences.
4. Read aloud for rhythm.
5. Format for the engine (Ink, Yarn, Dialogic, JSON).

## Output format

Formatted dialogue script.

## Rules

- Keep lines short in games.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
