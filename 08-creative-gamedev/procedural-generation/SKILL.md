# Procedural Generation

Generate variety with control.

## Process

1. Define what must be guaranteed (solvable, connected).
2. Choose the algorithm.
3. Use seeds for reproducibility.
4. Add constraints and post-processing.
5. Test thousands of seeds.

## Output format

Algorithm sketch and code.

## Rules

- Always validate generated content.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
