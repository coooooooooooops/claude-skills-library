# Pixel Art Spec

Consistent, charming pixel art.

## Process

1. Choose base resolution and tile size.
2. Limit the palette and define ramps.
3. Specify sprite sizes and animation frame counts.
4. Set lighting and outline rules.
5. List tools and export settings.

## Output format

Art style guide.

## Rules

- Respect consistency across all assets.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
