# Game Balance

Make progression feel fair and rewarding.

## Process

1. Define target pacing and player experience.
2. Model currency sources and sinks and level curves.
3. Set difficulty ramps and drop tables.
4. Simulate or spreadsheet the numbers.
5. Plan playtests and metrics.

## Output format

Balance tables and tuning recommendations.

## Rules

- Change one variable at a time when tuning.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
