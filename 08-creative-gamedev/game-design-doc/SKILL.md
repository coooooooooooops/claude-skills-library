# Game Design Doc

Define the game clearly before building it.

## Process

1. Write the elevator pitch and 3 design pillars.
2. Define the core loop and moment-to-moment gameplay.
3. Describe mechanics, progression, economy, and win/lose conditions.
4. List content, art, audio, and technical needs.
5. Define MVP scope and a milestone plan.

## Output format

A game design document in markdown.

## Rules

- Cut scope aggressively; define the smallest fun version.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
