# Compare Options Report

Decision-ready research.

## Process

1. Define the decision and criteria.
2. Research each option from reliable sources.
3. Summarize in a comparison table.
4. Recommend and list risks.

## Output format

Report with table and recommendation.

## Rules

- Cite sources and note dates.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
