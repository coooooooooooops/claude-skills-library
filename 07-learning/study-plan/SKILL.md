# Study Plan

Study smarter on a schedule.

## Process

1. Define the exam date or target skill and current level.
2. Break into topics weighted by importance.
3. Schedule sessions using spacing and interleaving.
4. Add practice tests and review blocks.
5. Plan rest and a final-week routine.

## Output format

Calendar-style plan with daily tasks.

## Rules

- Prefer active recall over rereading.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
