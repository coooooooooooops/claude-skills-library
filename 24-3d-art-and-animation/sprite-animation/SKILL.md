# Sprite Animation

Plan 2D sprite animation: frame counts, timing, spritesheets, and engine import.

## Process

1. List animations
2. choose frame counts
3. keep consistent pivots
4. pack spritesheets
5. set playback speeds

## Output format

Animation spec.

## Rules

- Keep pivots consistent across frames.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
