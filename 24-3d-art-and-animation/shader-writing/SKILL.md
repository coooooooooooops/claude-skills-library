# Shader Writing

Write shaders in GLSL, HLSL, or Godot shading language: lighting, effects, and optimization.

## Process

1. Define the effect
2. choose shader stage
3. write math step by step
4. expose uniforms
5. profile cost

## Output format

Shader code with comments.

## Rules

- Keep per-pixel math minimal.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
