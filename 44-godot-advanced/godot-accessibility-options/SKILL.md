# Godot Accessibility Options

Add accessibility: remappable controls, text scaling, colorblind modes, and subtitles.

## Process

1. Expose input remapping
2. add scalable UI
3. offer colorblind palettes
4. add subtitles
5. add reduced-motion toggles

## Output format

Options menu design.

## Rules

- Save options and apply at startup.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
