# Godot Mod Support

Add mod support to Godot games: PCK loading, resource packs, and safe scripting.

## Process

1. Define moddable data
2. load PCK or JSON at runtime
3. version the mod API
4. sandbox scripts
5. document for modders

## Output format

Mod system design.

## Rules

- Treat mod code as untrusted.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
