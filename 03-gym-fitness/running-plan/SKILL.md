# Running Plan

Build endurance gradually and safely.

## Process

1. Assess current fitness, target date, and days available.
2. Build a progressive weekly plan with ~80% easy running and one long run.
3. Limit weekly mileage increases to about 10%.
4. Include strength and mobility work.
5. Add taper and race-day tips.

## Output format

Week-by-week table and pacing guidance.

## Rules

- Increase mileage gradually.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
