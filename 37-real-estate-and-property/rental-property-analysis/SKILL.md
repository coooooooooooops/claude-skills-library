# Rental Property Analysis

Analyze rental properties: cash flow, cap rate, cash-on-cash return, and expenses.

## Process

1. Collect price, rent and expenses
2. compute NOI and cap rate
3. model financing
4. stress-test vacancy and repairs
5. summarize

## Output format

Analysis table.

## Rules

- Educational only; verify local numbers.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
