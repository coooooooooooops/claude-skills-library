# Speedrun Route Planner

Plan speedrun routes: splits, tricks, risk, and practice.

## Process

1. Study current route
2. segment into splits
3. practice hardest sections
4. weigh risk and reward
5. record and review

## Output format

Route notes.

## Rules

- Respect each category's rules.
