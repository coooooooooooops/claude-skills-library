# Data Entry Cleanup

Standardize and clean lists, names, addresses, and records for import.

## Process

1. Define target format
2. normalize case and spacing
3. split and merge fields
4. dedupe
5. export CSV

## Output format

Cleaned data and rules.

## Rules

- Keep the original data untouched.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
