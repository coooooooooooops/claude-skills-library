# Incident Readiness Plan

Prepare a small team's security incident plan: roles, contacts, and steps.

## Process

1. Define roles and contacts
2. list critical assets
3. document containment steps
4. plan communications
5. run a tabletop exercise

## Output format

Incident plan.

## Rules

- Practice before you need it.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
