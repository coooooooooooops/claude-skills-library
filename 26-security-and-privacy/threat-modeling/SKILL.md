# Threat Modeling

Threat model systems with STRIDE: assets, trust boundaries, threats, and mitigations.

## Process

1. Draw data flows
2. identify assets and boundaries
3. apply STRIDE
4. rank risks
5. assign mitigations

## Output format

Threat model table.

## Rules

- Defensive purpose only.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
