# Secure Code Checklist

Apply secure coding practices: validation, encoding, least privilege, and dependency hygiene.

## Process

1. Validate and encode input and output
2. apply least privilege
3. protect secrets
4. keep dependencies patched
5. log safely

## Output format

Checklist for the codebase.

## Rules

- Prefer well-vetted libraries.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
