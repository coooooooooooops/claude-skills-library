# Interactive Fiction Design

Design branching narrative and interactive fiction with Ink, Twine, or Yarn.

## Process

1. Define core variables
2. map branches and merges
3. write choices with consequences
4. manage state
5. test all paths

## Output format

Branch map and script.

## Rules

- Let branches reconverge to control scope.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
