# Fantasy Magic System

Design magic systems with rules, costs, limits, and consequences.

## Process

1. Define source and rules
2. set costs and limits
3. explore social impact
4. create conflict from limits
5. test with scenarios

## Output format

Magic system doc.

## Rules

- Limits create better stories than powers.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
