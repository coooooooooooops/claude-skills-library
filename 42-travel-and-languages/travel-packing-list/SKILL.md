# Travel Packing List

Build packing lists by destination, weather, and trip length.

## Process

1. Check weather and activities
2. list essentials
3. pack carry-on first
4. add documents and chargers
5. review

## Output format

Packing list.

## Rules

- Check airline baggage rules.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
