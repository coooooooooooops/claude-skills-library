# Remote Team Practices

Set up healthy remote team habits: async communication, documentation, and rituals.

## Process

1. Define working agreements
2. choose async vs sync channels
3. document decisions
4. schedule social rituals
5. review quarterly

## Output format

Working agreement document.

## Rules

- Default to written and asynchronous.
- Ask at most one or two clarifying questions when key inputs are missing; otherwise state assumptions and proceed.
- Match the user's level and tone; keep the response as short as the task allows.
